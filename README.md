# Prommmt

**Prommmt** is an AI image & video generation platform and prompt-sharing community. Users refine ideas into optimized prompts, generate media across a range of state-of-the-art models, and discover, organize, and share their creations alongside the prompts that produced them.

## Features

- **Prompt engineering** — Refine short ideas into polished, cinematic prompts, or extract a reusable prompt from any reference image (powered by OpenAI).
- **Multi-model generation** — Text-to-image, image-to-image, text-to-video, image-to-video, and video-to-video across models from Google (Nano Banana / Gemini), OpenAI (GPT Image), ByteDance (Seedream), Kling AI, Flux, and Stability routed through the AIML API gateway.
- **Community & discovery** — Public/private images, likes, favorites, collections, a discovery feed, and semantic search over image embeddings.
